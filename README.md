
# AI-Based Hybrid Network Intrusion Detection System

A final-year cybersecurity project exploring machine-learning-based network intrusion detection using the CIC-IDS2017 dataset.

## Objectives

- Detect known network attacks using Random Forest.
- Identify anomalous traffic using Isolation Forest.
- Develop a hybrid detection strategy.
- Evaluate detection performance on unseen attack categories.
- Visualize results through an interactive dashboard.

## Technology Stack

- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- Streamlit and Plotly

## Dataset

We use CIC-IDS2017 from the Canadian Institute for Cybersecurity.

Official source: https://www.unb.ca/cic/datasets/ids-2017.html

The dataset files will not be stored in this repository.
